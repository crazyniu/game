4. **主菜单**：按追加要求移除大白卡，标题直接置于森林上，树冠小鸟眨眼、偶尔有鸟飞过，悬浮 Play/Levels/Settings；Play 恢复当前保存对局。

6. **Hint**：后台线程求最优下一步，来源/目标各有光圈和中英文标牌，每关累计 3 次并存档；节点/时间预算失败显示暂无提示，不扣次数，不阻塞主线程；棋盘变化、换关或离开游戏页时不应用旧结果。
7. **v4 存档**：保留 v3 的当前关、有效移动、通关/解锁记录；新增逐关最高星、提示次数、撤销/重开计数、已看教程、语言。旧档迁移保留备份。音频设置独立升级到 v2，保留旧开关并为新增音量赋 100%。
8. **追加表现调整**：早期少量栖木加大行距、上移并略放大鸟，缩小顶部空白；睡眠 Z 放大 1.6 倍；顶部两侧 96 片彩纸，约 2 秒。板条箱增加只读条件牌（还需几群 / 集齐图示鸟种），使第 20 关的揭示说明与盘面对应。

## 自行决定与明确规则

规则已同步到 `docs/DESIGN.md` 的 T11 节。

- 按协调者最终要求采用 UI_SPEC §3.4：撤销与重开合计 0 次得 3 星，合计 1–3 次得 2 星，合计 ≥4 次得 1 星。提示不影响星级，星级不影响解锁。保留最高星。
- 未通关关卡退出/重进保留撤销/重开计数；已通关后的 Replay 或关卡页重玩开始新的评级对局。有效步数排除已撤销步骤；最优步数读取原关卡的 `solverMinMoves`。
- v3 已通关关卡没有辅助使用历史，迁移授予基准 1 星，重玩可提升；不伪造历史 3 星。
- Hint 为每关总共 3 次，重开/重玩/重启应用不补充，重置进度才清空。Solver 预算 6000 节点，UI 等待最多 1.5 秒；只展示已证明最优解的首步。超时任务仍受节点预算约束，结束前不会再启动并发搜索。
- 教学在 Skip/知道了后记为已看；仅打开关卡或关闭应用不算完成。“重看引导”清除记录，随后进入对应教学关可重看。
- 使用 Fredoka 主字体+Noto Sans CJK SC 静态 SDF 后备字体。双语言各 89 个键，生成字体时验证实际文字覆盖，附 Noto 的 SIL OFL 许可。文字最小为 26 个参考画布像素。
- 保留已有音频资产范围：当前没有 BGM，音乐开关/音量保存且连接 AudioManager，BGM 素材仍由 T13 提供。隐私政策 URL 为 `https://example.com/perch-sort/privacy`，集中在 `GameController.PrivacyUrl`，按任务约定由 T14 替换。版本号读取 `Application.version`（当前 0.1.0）。
