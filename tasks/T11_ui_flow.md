# T11 — UI / 流程 / 新手引导（按上线标准）

现状：已有菜单、关卡选择、设置、暂停、通关页、死局页（见 `build/screens/06~11`、`04-win.png`），玩法 v2 与真美术已接入（T10 系列已验收）。Unity 编辑器未开，你独占项目。先自己看一遍现有截图与 `Scripts/UI`、`SceneBuilder` 再动手。

## 必须做
1. **新手引导（渐进、可跳过、只出现一次，存档记录）**：
   - 第 1 关：手指提示“点击栖木→点同色栖木/空栖木”；说明“外露端连续同色会一起飞”。
   - 第 2 关：提示顶部鸟巢：“把鸟群集齐 6 只送回对应的鸟巢（亮着的前两个）”。
   - 第 3 关：说明睡眠：“集齐但鸟巢还没轮到 → 睡着，轮到时自动回巢”。
   - 首次出现篮子的关（第 8 关）、板条箱（第 11 关）、短枝（第 12 关）、揭示条件（第 20 关）各有一次性小提示卡（标题+一句话+示意图用现有素材）。
   - 引导用半透明遮罩+聚焦+手指动画（程序绘制或现有素材），不阻塞核心玩法；设置里可“重看引导”。
2. **通关页**：奖杯+星星（按撤销/重开次数给 1–3 星，规则写进 DESIGN 并有测试）、本关步数 vs 最优步数、按钮 Next Level（主）/Replay/Home；最后一关通关后显示“全部通关”页并提示更多关卡将到来。
3. **关卡选择**：为 ≥100 关设计（滚动网格或分页），显示星数、锁定态、当前关高亮，进度汇总；关卡数据量变化不改代码。
4. **主菜单**：Logo 字样（原创标题 “Perch Sort” 工作名先沿用）、Play（继续当前关）、Levels、Settings；背景用现有森林，鸟偶尔飞过/眨眼的轻动效。
5. **设置/暂停**：音乐/音效开关与音量、震动、减少动画、重看引导、语言（English / 简体中文，运行时切换并存档，所有文案走 `Strings`，缺项有测试）、重置进度（二次确认）、隐私政策/版本号入口（URL 占位常量，T14 替换）。
6. **提示道具（无广告）**：游戏内一个 Hint 按钮：用 Solver 求下一步最优移动并高亮来源/目标（每关限 3 次，次数存档；求解超预算则提示“暂无提示”，不能卡死 UI；放后台线程或分帧，禁止主线程长卡顿）。
7. **体验细节**：按钮点按反馈（缩放+音效）、页面转场、手机返回键/ESC=暂停、安全区、小屏与长屏不重叠；无障碍：色盲友好（鸟已靠轮廓区分）、字号下限。
8. 存档版本升至 v4（新增星、引导已看、提示次数、语言）；v3 → v4 迁移保留进度；测试覆盖。
9. 测试：PlayMode/EditMode 覆盖引导状态机、星级规则、提示（求出的提示移动在 Core 上合法且使最优步数-1）、语言完整性、存档迁移、关卡选择在 40/100/300 关下构建不报错。`bash scripts/run_tests.sh` 全绿；`scripts/screenshots.sh` 增补：引导各步、通关页、关卡选择、设置、中文界面、提示高亮。
