### 对齐与透明边缘

- 所有鸟的**脚底接触线为 y=870**（从画布顶边计），底部约留 15%。鹦鹉尾尖自然低于脚底，不能用整张 alpha 外框的最低点对齐脚。
- 鸟的可见外框水平居中，保持各自高矮与尾长。长尾鸟的脚不在外框水平中心；`manifest.json` 对每只鸟提供 `footCenterPixels` 和从左下计的 `unityPivot`，用于脚部落位。
- 源图存在 alpha 为 1～7 的零散噪点；导出脚本清零这些像素，保留其余抗锯齿透明度。缩放使用预乘 alpha，最终转回普通 RGBA，避免透明像素中的隐藏颜色混入边缘。
- 没有对白鸽的浅色羽毛做白色抠图。鸟、栖木、树冠都是真实 alpha；不是白底或棋盘格底图。

## 复核与再导出

从项目根目录运行验收命令，无需安装任何 Python 包：

```sh
python3 art/tools/check_assets.py
```

检查 14 张生产图和 2 张总图的 PNG 数据/尺寸；12 张透明生产图必须为 RGBA，四角及四周 16px 必须透明，主体必须有不透明像素；10 只鸟在 y=870 有接触像素；背景、图标和总图不透明；64px 总图为真正灰度 PNG。失败时返回非零退出码。

使用当前已有 Pillow 的本地环境再导出：

```sh
art/.venv/bin/python art/tools/build_assets.py
```

如另建环境，只需安装 Pillow。重新导出不调用图像服务，不需要 API Key；会从 `source/` 重建生产图、总图、QA 图和 `manifest.json`，保留生成母版及提示词。

### 睡眠方案选择

原图眼睛是带白色高光的深色实心椭圆，透明闭眼线无法遮住已有眼球，直接叠加会穿帮。因此采用任务第 6 项允许的替代方案：每种鸟分别以自身原图作编辑目标，生成闭眼版，保持物种外形与大花纹，导出时对齐原版 alpha 外框和脚部基准。**接入时切换 `bird_XX` → `bird_XXs`，再以代码执行轻微压扁、变暗和 Z 气泡，不要在原睁眼纹理上盲叠闭眼线。** 独立闭眼线仍交付，供将来可分层的鸟脸使用。生成编辑并非逐像素眼区替换，局部羽毛/腮红有轻微差异，比较图已展示真实结果。
