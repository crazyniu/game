## Reference boundary
These retained pictures do not override later approved layouts, forest-only scenery or shared components. Follow the current screen contract for component sizes, lettering, controls and frame styles. Runtime birds use the game's own animation frames, not characters painted into these reference pictures.

Rule (user, 2026-11-11): every design image of this game lives in this folder and nowhere else. New or revised designs replace the file of the same screen here; old designs live only in Git history. Current shared components and approved screen contracts define the style; the retired component board is not a current constraint.
