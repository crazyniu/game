# Perch Sort — UI 设计规范 v1（Claude 制定，Codex 实现）

画布 1080×1920（9:16），Canvas Scaler 参考分辨率同此；所有坐标以画布中心为原点，单位 px；安全区外不放交互元素。验收以本文为准，逐项对照。

## 1. 设计语言：「树屋手作」
游戏本体是暖色手绘插画（奶油栖木、藤编巢、木箱）。UI 必须是**同一世界里的物件**，而不是悬浮的扁平色块：
- 材质：**原木板**（面板）、**树叶/苔藓绿**（主按钮）、**奶油布/纸**（次按钮、卡片内底）、**藤条**（描边装饰）。
- 形态：圆润大圆角、2–3px 暖棕深色描边（#5A3A22）、左上高光、右下柔影，和鸟/栖木线宽一致。
- 禁止：纯白大卡片、纯色无描边矩形、系统默认控件观感、硬投影黑边、霓虹渐变。
- 每个页面必须能一眼看到「森林背景 + 至少一个角色/物件的装饰」，不得只有面板和按钮。

### 色板
| 用途 | 色值 |
|---|---|
| 墨绿文字 / 深描边文字 | #34502A（文字）、#5A3A22（木棕描边） |
| 主按钮（树叶绿） | 渐变 #7DBB4B → #4E8A2E，描边 #2F5A1B |
| 次按钮（奶油） | #FFF3D0 → #F2DDA2，描边 #B98F55 |
| 木面板 | #D9A566 → #B97F45，内嵌奶油纸 #FFF6DD |
| 强调金 | #FFC93C；星灰槽 #CDBB93 |
| 警示（仅死局/重置） | #D9644A |
| 遮罩 | #1E2B14 @ 55% |

### 字体
- 英文/数字：Fredoka（已有）；中文：Noto Sans SC 回退（已有）。
- 层级（画布 px）：Logo 160；页面标题 84；按钮 52；正文 40；次要说明 32（**任何文字不得小于 32px**）；HUD 数字 56。
- 标题/Logo/大数字用**描边文字**（木棕 6px 外描边 + 轻微下投影）；正文无描边、墨绿。

## 3. 页面规范

### 3.1 主菜单
- 背景：森林全屏；**不放大白卡片**。
- Logo：中心偏上，y=+420，宽 860；木牌/树枝拼出 “Perch Sort”，带描边大字，字下是一行副标题 “A little order. A happy flock.”（32px）。
- 主视觉：Logo 下方（y=+80）一棵大树冠，里面坐 3 只不同的鸟：轮流眨眼、偶尔歪头；每 8–12 秒有一只鸟飞出屏幕再飞回（可 reduce motion 关闭）。
- 按钮：竖排居中，y=-330 / -480 / -610：**Play**（主按钮，宽 640）、**Levels**（次，宽 560）、**Settings**（次，宽 560）；Play 上有轻微呼吸缩放 1.0↔1.03（2s）。
- 底部 y=-780：小字进度 “12 / 100” + 星星总数；右下角版本号 28px 半透明（唯一允许 <32）。
- 进入动画：Logo 从上落下弹性停靠 0.5s；按钮依次 0.08s 间隔淡入上移。

### 3.2 关卡选择
- 顶部木牌标题 “Levels”（84），左上返回圆钮，右上总星数徽章。
- 网格 4 列，格 150×170，水平间距 36，垂直间距 30，纵向 ScrollRect（惯性、边缘回弹），首次打开自动滚到当前关。
- 章节分隔：每 10 关一条藤蔓分隔条 “Meadow / Grove …”（命名：1 Meadow、2 Grove、3 Creek、4 Orchard、5 Cliffs、6 Canopy…，随关卡扩展可配置）。
- 当前关绿牌 + 光环脉动；完成格显示 3 个小星槽；锁定格点击轻抖并提示 “Finish the previous level”。
- 底部固定渐隐条，避免内容被系统手势区遮挡。

### 3.3 游戏 HUD
- 顶部木牌（y=+850，宽 960 高 130）：左 “Level 12”（56 描边）；中间鸟巢进度：小蛋图标 × 已完成/总数，完成时蛋亮起；右圆形暂停钮。
- 底部（y=-800）三个圆钮横排：**Undo、Hint（带剩余次数角标）、Restart**，各 150 间距；不再用两个大条形按钮。
- 提示文字条只在引导关出现，不常驻。
- 棋盘区域限定在 y∈[-640, +700]，棋盘整体在此区域内垂直居中。

### 3.4 通关页（覆盖在棋盘上，遮罩 55%）
- 自上而下：奖杯+当前主角鸟（y=+420，高 420）→ 3 星槽（y=+170）依次弹出（每颗 0.35s，弹跳+闪光+音效递升）→ 标题 “Well flown!”（84 描边，不与奖杯重叠，间距≥40）→ 副行 “Moves 14 · Best 12”（40）→ 按钮：**Next**（主，y=-250）、**Replay**（次，y=-400）、**Home**（次，y=-530）。
- 无面板白卡：内容直接浮在遮罩上，下方放一块半透明木牌承托按钮区。
- 彩纸：从屏幕顶部左右两侧各一束喷发（各 60 片，3 种纸片，随机色），重力+旋转+摇摆，持续约 2.2s，铺满画面；reduce motion 下改为静态少量。
- 3 星规则（写入 DESIGN）：撤销+重开总次数 0 → 3 星；1–3 → 2 星；其余 → 1 星。
- 最后一关通关：标题 “All flocks home!” + “More levels coming soon”，只有 Home/Replay。

### 3.5 设置/暂停（同一木面板，模态）
- 木面板宽 900，高自适应（≤1300）居中；标题 “Settings/Paused”（84）；分组：Sound（音乐、音效滑条+开关）、Vibration、Reduce motion、Language（英/中分段钮）、Replay tutorial。
- 底部：主按钮 Resume/Close；暂停时多一个次按钮 Home；危险操作 Reset progress 放最底、红色小字按钮，点击二次确认弹窗（再次木面板，按钮 Cancel/Reset）。
- 行高 130，左标签（40）右控件；行间有藤条分隔线。

### 3.6 死局页
- 小木牌弹窗（不整屏遮罩）：标题 “No moves left”（84）+ 一句话 + 按钮 **Undo**（主）/ **Restart**（次）；弹出时棋盘仍可见，微暗 25%。

### 3.7 新手引导
- 聚焦遮罩：全屏 55% 暗，目标区域镂空（软边），手指指示 + 涟漪循环；提示卡在上方或下方（避开聚焦区）。
- 提示卡：宽 860，纸卷轴样式，标题 56、正文 40、按钮「Got it」。每步可点空白处继续；右上 “Skip”（次要小钮，≥32px）。

## 4. 动效总则
- 缓动：进入 ease-out-back（0.25–0.45s），退出 ease-in（0.18s）；页面切换交叉淡入 0.2s + 位移 24px。
- 弹窗：遮罩淡入 0.2s，面板从 0.85 缩放弹到 1.0。
- 全部动效尊重 Reduce motion（去弹性/抖动/粒子，保留淡入）。
- 禁止每帧分配；粒子复用池。

## 5. 素材清单（T11b 出图，Codex image_gen，风格同 art/raw）
`ui/panel_wood`、`ui/paper_inner`、`ui/btn_primary(+pressed)`、`ui/btn_secondary(+pressed)`、`ui/btn_round`、`ui/toggle_track/knob`、`ui/slider_track/knob`、`ui/hud_bar`、`ui/level_cell_{done,current,open,locked}`、`ui/star_on/off`、`ui/tip_card`、`ui/hand_pointer`、`ui/logo_perch_sort`（含描边大字，**不含**其他文字）、`ui/vine_divider`、`ui/egg_on/off`、图标（pause、undo、restart、hint、back、sound、music、vibrate、lock、home、globe）、`ui/menu_tree`（大树冠，鸟另放，便于动画）。九宫格素材提供原图与边距表。

## 6. 验收清单（Claude 逐项勾）
1. 所有页面无纯白大卡片、无无描边色块按钮，材质统一。
2. 任意文字 ≥32px（版本号除外）；无重叠；中英文长度都不溢出。
3. 主菜单：Logo/树冠鸟/按钮位置与 §3.1 一致，鸟有眨眼与飞出动画。
4. 关卡选择：滚动、章节分隔、星槽、当前关脉动；100/300 关不卡顿。
5. HUD：三个圆钮 + 蛋进度；通关页三星依次弹出、彩纸铺满。
6. 弹窗/页面切换动效符合 §4；Reduce motion 生效。
7. 1080×1920、1080×2340、1440×1920 三种比例截图均无错位。

# v1.1 修订（2026-10-31 Claude 逐张走查 T11c 中间截图后制定，优先级高于上文）

## A. 改为“常见休闲手游”统一风格（全局硬规则）
1. **文字只有两种样式**：
   - **亮字**（所有标题、按钮文字、HUD 文字、横幅文字）：白色 #FFFFFF，粗体，深棕外描边 #5A3A22 厚度 0.22（TMP outline）+ 下投影 (0,-4) #3A2414 60%。
   - **暗字**（只用于奶油纸/卷轴/面板内的说明正文）：深棕 #5A3A22，无描边。
   - 禁止再出现墨绿字、灰字、红字（重置按钮除外，见下）、绿字在灰底等其它组合。
2. **按钮**：主按钮=绿色（btn_primary）、次按钮=橙色（新素材 btn_orange），文字一律亮字；奶油色 btn_secondary 只用作设置里的分段选择未选中态。危险操作=红色小按钮（新素材 btn_red）+亮字。
3. **弹窗统一结构**：全屏遮罩 #000 50%（盖住棋盘与 HUD，弹窗期间 HUD/棋盘不可点）→ 居中木面板 → 面板顶部压一条**标题横幅**（新素材 ribbon_title，亮字标题）→ 右上角圆形红色关闭钮（btn_round + icon_close，可关闭的弹窗才有）→ 内容 → 底部按钮。
4. **层级**：UI Canvas 必须在所有棋盘 Sprite 之上（Screen Space Overlay 或 sortingOrder 高于棋盘）。**弹窗出现时棋盘不得穿透到 UI 上方**（当前通关页栖木压住标题和星星，是严重 bug）。
5. 文字永远不得溢出或换行断字：按钮文字自动缩放（TMP Auto Size，min 32）。

# v1.2 修订（2026-10-31 用户要求，优先级最高）

## 1. 设置极简
- 设置弹窗只保留**一个声音开关**：圆钮，开=icon_sound，关=icon_sound_off；点击切换静音/取消静音（同时作用于音乐和音效）。**删除**音量滑条、音乐单独开关、振动、减少动画、语言、重看引导、重置进度、版本号。
- 被删项的默认行为：振动=开；减少动画=跟随系统（无系统 API 时=关）；语言=跟随系统语言（中文系统→简体中文，其余→英文）；重看引导/重置进度不提供入口。存档字段保留不删，只是不在 UI 暴露。
- 设置弹窗结构：遮罩 + 小木面板（宽 560 高 460）+ 右上红色关闭圆钮 + 中央一个大声音圆钮（直径 200）。无标题文字。

## 2. 能用图标就不用文字
所有按钮只显示图标，不显示文字（含中英文）：
| 位置 | 按钮 → 图标 |
|---|---|
| 主菜单 | Play → 绿色大圆钮 + icon_play（直径 260，呼吸动画）；Levels → 橙色圆钮 + icon_levels（直径 150）；设置 → 右上角圆钮 icon_settings |
| 关卡选择 | 返回 → icon_back；标题“Levels”删除，只保留星数胶囊（星图标+数字） |
| 游戏 HUD | 暂停 icon_pause；底部 Undo/Hint/Restart 只显示 icon_undo / icon_hint / icon_restart，**删除下方文字**；Hint 角标数字保留 |
| 暂停弹窗 | 继续 icon_play（绿，大）、重开 icon_restart、主页 icon_home、声音 icon_sound/off；无标题文字 |
| 通关页 | Next → 绿色大圆钮 icon_next；Replay → icon_restart；Home → icon_home；保留三星与奖杯；“Level Complete!”横幅删除文字，改为横幅上只放三颗星（或删除横幅）；步数行删除 |
| 死局弹窗 | icon_undo（绿，大）+ icon_restart；可保留一个“无路可走”的图示（空栖木+问号图标 icon_question），不放文字 |
| 引导 | 允许保留**极短**文字（≤ 6 个英文词/≤ 10 个汉字），能用手指动画表达的步骤不放文字 |
| HUD 关卡名 | 只显示数字“1”在木牌胶囊里（可加小旗图标 icon_flag），不写 “Level” |

## 3. 不用异形按钮
- 按钮形状只有两种：**圆形**（所有图标钮）和**圆角矩形/胶囊**（如有必要的长按钮，本版本原则上不再需要）。
- 不用横幅、卷轴、拱顶牌等异形作为可点按钮；关卡格统一为同尺寸圆角方块（done 格的拱顶造型不用，done 用 open 格底 + 下方三颗小星）。
- 同类按钮同尺寸：大主钮 200–260，普通圆钮 150，HUD 圆钮 130。

## 4. 新图标（T11b5 生成到 art/ui_kit/）
icon_play、icon_next、icon_levels（2×2 网格）、icon_sound_off（喇叭+斜杠）、icon_question、icon_flag。

# v1.3 修订（2026-10-31 Claude 走查 T11c 交付后，优先级最高）
坐标为 1080×1920 设计坐标，原点在屏幕中心，y 向上为正。

1. **遮罩**：所有弹窗（暂停/设置/死局/通关）遮罩 = 纯黑 #000000、alpha 0.5，铺满全屏并盖住 HUD；0.2s 淡入。弹窗打开时 HUD（暂停钮、关卡牌、底部三钮）不得以“半灰”状态露在遮罩上。
2. **弹窗打开动画**：面板 scale 0.85→1.05→1.0（共 0.25s，OutBack），alpha 0→1 只在前 0.1s；关闭为 1.0→0.9 + alpha→0，0.15s。不能只做透明度渐变。
3. **通关页**：面板 860×1120，居中于 y=0（不再撑满全屏）。顶部放 ribbon_title（无文字）中心 y=+520，三颗星坐在横幅上，中心 y=+540，间距 190，中星大 1.2 倍。小鸟+奖杯中心 y=+180。Next：Ø220 绿 + icon_next，y=-220。Replay/Home：Ø150 橙，(±150, -420)。棋盘与 HUD 全部在遮罩下。
4. **死局弹窗**：面板 760×640，居中。上部图示只用一个 btn_round_red（不可点，Ø160）内放 icon_question，中心 y=+130；删除“问号+空栖木”组合。下部两钮**同尺寸** Ø200：撤销 = btn_round_green + icon_undo 在 (-150,-130)；重开 = btn_round_orange + icon_restart 在 (+150,-130)。不得使用灰绿或木底。
5. **关卡选择**：删除章节标题胶囊和藤蔓分隔线（草甸/林地/…），关卡连续排成 4 列网格，中间没有空位。已解锁格的数字用深棕 #5A3A22、字号 64、无描边；锁定格保持灰底白字+深色描边；当前关（绿格）= 最小的“已解锁且未通关”关卡（通关 1–5 后应是 6）。滚动区底边 y=-760，底部 120px 渐隐，不能出现硬切线。
6. **引导气泡**：气泡位置固定在 y=+420（鸟巢下方、棋盘上方），永远不得压住任何栖木、鸟或鸟巢；第 3 关当前压住第二行，必须改。
7. **Skip 钮**：木底圆钮（与 HUD 同款）Ø130 + icon_next，不用橙色。
8. **HUD 关卡牌**：缩到 240×100（只放一个数字，不要空长条）。
9. **菜单→游戏转场**：禁止双重叠影。顺序：菜单内容 0.25s 淡出到只剩背景 → 然后 HUD 淡入 + 棋盘入场动画。转场中任何时刻不得同时看到菜单 Logo 和棋盘。
10. **从主菜单打开设置**：菜单内容保留在遮罩下（不要隐藏）。
11. **死局按钮补充**：有撤销历史 → 绿 Undo + 橙 Restart（第 4 条坐标）；无撤销历史 → 隐藏 Undo，Restart 居中 (0,-130) Ø200。任何界面都不显示“看似可点实际禁用”的彩色按钮。
12. **通关横幅尺寸**：ribbon_title 922×180，中心 (0,+520)；星 150/180/150，x=-190/0/+190，y=+540（中星 +560）。
13. **遮罩数值修正**：项目为 Linear 色彩空间，遮罩 #000 alpha 改为 **0.72**（视觉≈sRGB 背景 ×0.5）。暂停/设置/死局打开时 HUD 保持原色、仅被遮罩压暗（不加禁用灰）；通关序列开始时 HUD 0.2s 淡出隐藏，下一关入场时淡入。
