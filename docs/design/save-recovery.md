# Save recovery screen

A new safety-only state, not a redesign of an accepted page. Use the existing
JungleDialog green frame/wooden heading, forest backdrop and ButtonKit green buttons. Center the heading,
four-line explanation and two equal 420 x 150 action buttons below the frame
on the 1080 x 1920 canvas. The heading uses the shared sign's visible face; body
has 30 pixels of additional top/bottom clearance to avoid the wooden header. No decorative bird, reward, coin counter, shop shortcut or dismiss button.

English and Chinese words are newly AI-painted transparent atlas assets
(label_save_recovery_en / label_save_recovery_zh), fitted by measured visible ink.
Title: Save Error / 存档异常.
Explain that the save cannot be read, original files remain, play and purchases
are paused, and the player can retry after restoring a backup or exit.
Actions: Retry / 重试 and Exit / 退出.
No font-rendered game words or extracted mockup pixels.

Preview uses the canonical save_recovery.gd interface with no data mutation.
Runtime capture is local evidence only, not an approved baseline until reviewed.
