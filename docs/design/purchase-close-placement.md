# Purchase Close placement

For booster, nest, outfit-confirmation and CoinShop Preview dialogs, retain the existing coin-shop Close image and dimensions. Its hit rectangle ends exactly 48 design pixels above the existing panel, with its original horizontal placement. Title, panel and lower action geometry stay unchanged.

This opt-in rule is local to PurchaseDialog. Full-screen Draw navigation remains in its existing top-left page position; a full-screen page does not use the card's outside-frame formula.
