# Delivery

Home selects the painted Fly Home or 枝头小分队 hanging sign with the active locale and retains the live perch below it. Browser titles use the game language. The native export pipeline localizes launcher names by system language while retaining the existing technical project and save identity.

The App Store and Google Play listings in store/listing.md include U.S. English and Simplified Chinese text. All ten portrait masters carry the localized game name, and both feature graphics use the localized title. The platform export contains 35 portrait posters, two landscape graphics, and the three existing text-free character icons. The localized art and narrow crops were inspected; no runtime build, device acceptance, or store submission was performed.
