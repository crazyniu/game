# Map node consistency repair

The user's marked current runtime screenshot identifies three defects: unequal level-node
sizes, inconsistent rating presentation and a bird displaced into the right edge scenery.
Work is based on the current cloud integration tree, without remote upload or publication.

Reuse accepted production art byte-for-byte. All locked, cleared and current node faces use
one 150px visible-ink box and one tap-target size. Cleared/current numbers use the same cap.
Current state is indicated by a modest glow and the live bird rather than a larger disc.
Rating stars retain the accepted island full/empty pair and are fitted by visible alpha bounds
to identical 38px slots, centred in an equally spaced row at the node's lower rim.

The current bird is uniformly sized to 85% of the existing map scale and sits on the top rim.
Its measured front-frame ink centre is registered to the node's centre, not the sprite canvas.
Rows above the active row gain 160px of vertical clearance, remaining below the header.
Retain local sibling drawing order so map elements never escape over later modals.
No profile, progression, level content, rewards, signal ownership, or accepted asset changes.

Verify all 100 current-level layouts, same-size nodes/tap areas, star ink fits, actual bird-centre
registration, navigation and modal local-layer ordering, English/Chinese captures and
timed live bird motion. Inspect the actual GUI screenshots before delivery. User approval and
physical mobile-device testing remain separate from cloud self-checks.
