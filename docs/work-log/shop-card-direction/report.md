# Shop preview delivery

Generated a full-page booster-shop proposal with the native image tool and saved it in the canonical
`art/approved_ui/shop.png`. The proposal uses six equal pale product cards, prominent existing item
illustrations, smaller names/stock, consistent numeric gold prices, a freestanding title and three
independent category icons. Coast/sand and dimensional painted materials follow Home.

Exact prompt, output source and approval gate are in `docs/design/shop.md`. The user must confirm
this direction before implementation. No `shop_view.gd`, shared helper, catalog, price, inventory,
purchase behavior or production Shop artwork was changed by this preview task.
