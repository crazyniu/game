# Board HUD generation prompts

Built-in image_gen was used with `transparent_background: true` for every asset. One request per asset. The open-door request used the generated goal_house_single image as its edit target; other requests generated individual sprites after the approved references had been viewed. Export processing resized the sprites, preserved alpha, removed alpha values 1–12, and prepared a repeating lower rope strip. No fallback API or CLI model was used.
