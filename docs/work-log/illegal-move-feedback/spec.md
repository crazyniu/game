# Illegal-move feedback with drawn head-shake frames (OMP worker, owned: BirdView.cs and BirdIdleGroup.cs only) - issue 50

Design (docs/GAME_DESIGN.md section 1): tapping an illegal target makes the selected birds shake their heads, then the selection cancels, nothing else changes. Today `BirdView`'s invalid-feedback entry plays a blink, which does not read as refusal; shaking or mirroring a still is forbidden.
Implement with drawn frames: `<species>_turn_left_01..04` and `<species>_turn_right_01..04` (exist for sunny, sky, berry; other species have none yet). Sequence per selected bird: turn_left 01,02,03 forward, then 02,01 back, then turn_right 01,02,03, then 02,01 back, then idle: 10 frames at 16 fps = 0.625 s. Birds of the run start 0.04 s apart from the tip bird outwards. Selection cancels when the LAST bird finishes (keep the existing callback semantics and input lock; do not extend the lock beyond 0.7 s). Body stays on its seat (no positional movement, no rotation, no scale change except the normal breathing). Species without both sequences fall back to the existing blink (documented, tested).
Honour `GameMotion.Instant`. Do not touch flights, idle scheduling, or anything outside the invalid-feedback path. Tests (new file `Tests/PlayMode/IllegalMoveFeedbackTests.cs`): an illegal transfer on level 1 plays frames named turn_left then turn_right in order with timings within one frame of the table, never a negative scale.x, selection cancelled afterwards, board state unchanged, a species without sequences plays blink. Evidence: 0.05 s contact sheet of an illegal move on level 1 under `docs/work-log/illegal-move-feedback/evidence/`. Serialized Unity (`flock /tmp/unity.lock`), full suite green with unchanged existing counts, report `docs/work-log/illegal-move-feedback/report.md`.
