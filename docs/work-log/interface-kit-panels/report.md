## 生成与整理

对照 `docs/UI_SPEC.md` §1/§2/§5，已目视读取 `bird_01.png`、`crate.png`、`trophy.png`，以其暖棕轮廓、左上高光、右下柔和暗部、木/叶/奶油材质为生成依据。完整逐资产提示词保存在 `sources_a.json`，木面板记录为生成提示摘要。

内置工具输出的选定原画复制进 `source_a/`，不修改默认生成目录原件。Pillow 仅执行已获协调者许可的裁切、尺寸整理、透明外部杂点清理、按下态派生、平铺边缘处理和预览合成：

- 清理远离主体的 alpha≤8 杂点；主体 alpha>8 区域向外保留 2 个源像素的保护带，保护带内抗锯齿 alpha 不变。
- 缩放采用预乘 alpha，避免透明像素的 RGB 背景污染边缘。
- 按下态 RGB 精确乘 0.92，alpha 不变，向下移动 6px；正常态预留底部空间，按下态不裁掉主体。运行时使用按下纹理时无需再叠加一次 6px 位移。
- 藤条由生成片段及其水平镜像组成周期，左右接缝列像素完全相同。
- 木轨第一版带多余光晕，选用重生成版本；卷轴经内置工具透明背景编辑后选用，并以实际 alpha 和合成预览确认透明效果。

复现命令：`uv run --with pillow python art/ui_kit/build_a.py`。
