# Win rewards: spec

User request (2026-11-09): every cleared level gives boosters so players build the habit of using them; more coins,
so watching ads for coins can be added later. Amounts decided by the developer.

- First clear drops 1 booster, 2 with three stars, 3 on every fifth level. A replay drops 1 with 30 percent chance.
- The first drop, and half of the rest, favour a booster that helps on the next level.
- Coins: first clear 50/80/120, replay 20, each improved star 30, chapter 500, chest 300 + 3 boosters, daily challenge
  150, check-in 100/120/160/200/240/300/600 with 1/1/1/1/2/2/3 boosters.
- The start-of-level gift popup goes away. At level start a hand points at a held, fitting, never-used booster. After
  12 s without a tap the hint tool is pointed at, once per level, only with hints in stock.
- Ads are out of scope; no placeholder buttons.
