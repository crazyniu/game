## 1. Zero-stock plus badge (HUD)
Each tool except Undo shows a red disc badge top-right of its button. Stock >= 1: the number (existing). Stock == 0: a white plus sign (icon, no text) in the same red disc. Tapping a tool with stock 0 (hint, branch, level booster) opens the Shop on the boosters tab with that booster's card pulsing (scale 1.0 to 1.06 to 1.0, 0.6 s) and the confirm dialog NOT yet open. Closing the shop returns to the same level state (selection cleared, no restart, board untouched, input re-enabled). Today a zero-stock tap does nothing; inspect `GameRoot.TapBooster` and keep every other behaviour.

## 4. Rules for everything above
Icons only where an icon is clear; the only texts are numbers, species names, the personality line and the gift line. All buttons of one role have identical size in every state; disabled means dimmed, never smaller. Modals above all scene objects. No per-control animation except what is written. No mirroring. Do not touch `art/` or Resources art; use existing sprites; if a needed sprite is missing, STOP that item and list the sprite in the report.
