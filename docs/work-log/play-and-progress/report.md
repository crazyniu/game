# Changes

- The winning move settles the session immediately. The delayed win panel uses the saved payout. Map gates no longer play a false unlock celebration; actual unlocks lead to the new forest.
- Mandatory tool guidance resumes after a modal. Repeated hint requests share the current search; only solved continuations consume a Firefly. A swivel with no effect cannot consume a move.
- Equipment changes preserve the active shop detail. The original nest can be equipped again. Family levels show their mechanic badge, and four distinct chest reward groups fit above Confirm.
- Supported browser haptics follow the vibration switch independently of sound. Toggling sounds or vibration no longer restarts music.
- On localhost and HTTPS browsers supporting Web Locks, each persistent profile has one active writer. Other tabs wait and load its latest save when the writer closes. Direct level previews use an in-memory profile and invalid level numbers return Home.
- No tests, build, screenshots or runtime verification were performed for this repair. It is a source delivery for user acceptance.
