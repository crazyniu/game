## Changes

- List: two-column scroll board, gold portrait rings, painted species/unknown ribbons, brown painted house-count pills, and ability badges. The viewport exposes three rows and preserves the scroll position on returning from detail.
- Detail: header name ribbon, painted personality capsule, front-facing hero, four identical-size outfit tiles (default plus every existing catalog outfit), equipped glow/check, dimmed non-interactive locked silhouettes, ability badge with a painted caption capsule, and a house-count pill. All canonical outfits remain reachable; no catalog changes.
- Local coin header uses `PaintedNumber`, not `HudView.CoinHeader`. All numbers are brown painted glyphs. Fixed labels are aspect-preserving `PaintedLabels` images. The existing `Configure` font parameter remains solely to preserve the owner-controlled GameRoot call contract; it is not used to render text.
- Issue #103: list portraits, detail hero, outfit tile birds, and locked silhouettes derive only from `<species>_front` and `<species>_front_blink_*`. Front-only motion supplies continuous 2.6-second breathing and 12-fps blink sequences; it never selects sideways poses or mirrors a sprite. No generic `UiBirdLife` scheduler is used because it can choose sideways poses.
- Fake states use the Foundation `PreviewMap(GameProfile)` lifecycle and view-only presentation data. Preview outfit clicks mutate only the supplied presentation; real outfit clicks retain `GameRoot.ToggleCosmetic`. The generic switcher's return action restores the real profile and attempt. No GameRoot hook was required beyond the merged Foundation API.
