# 小鸟归巢：交互、动画与输入锁

版本：规范设计1.0 · 2026-10-31 · **DESIGNED / PENDING_GRAYBOX**。规则可评审，不代表代码已支持。规范用语与优先级见[文档入口](../README.md)。

## 1. 动画合同

时长均为**本项目建议设计值**，不是竞品实测。本页是时间、曲线和输入时机的唯一权威；静态位置/尺寸归[UI_SPEC](../UI_SPEC.md)，可复制任务见[ANIMATION_PROMPTS](ANIMATION_PROMPTS.md)。沿用现有原创角色/菜单UI；新蛋、临时枝状态提示为后续必要资源，不在本轮生成或重画。动画期间输入锁覆盖完整事件链。下表行名是可引用的稳定键；秒用s，间隔为相邻起飞开始时间差，单鸟时长不是整群总长。六鸟总飞行长=单鸟时长+5×错峰，不把整群压成单鸟时长。

| 触发 | 逐阶段表现与可操作时机 | 建议时长 |
| --- | --- | --- |
| 入场 | 来自菜单先播“菜单退场”，完成后再进入本段；两列栖木依次进入→鸟落枝→目标清楚；全部落稳才点选。Restart直接进入本段 | 棋盘段0.55–1.05s；枝间约0.05s；加载不计入 |
| 选中 | 仅run抬30design px、白描边/少量星点，其他鸟不抬；结束可点目标/取消；取消同时间回落，无规则动作 | 0.12–0.18s |
| 非法操作 | 无位置/鸟数/步数变化；来源或目标短闪描边，保持原位，回Idle。减动画仅描边、不抖动 | 0.12–0.18s |
| 移动起飞 | 收选中态，换fly姿势、轻转身、翅膀可见扑动，逐只错峰离枝 | 间隔0.05–0.07s |
| 弧线与落枝 | 逐只飞到实际槽位；部分移动只飞实际Count；脚底接枝、收翅、挤压回弹；末只落稳后播放已计算的后续事件（不由动画推进Core） | 单鸟0.35–0.45s，回弹0.12–0.18s |
| 孵化 | 前方鸟离开→外露蛋轻摇/裂壳→原位同种幼鸟→恢复可移动站姿；后面蛋仍遮挡 | 0.25–0.40s，无额外点击 |
| 满组等待 | 非当前种六只闭眼压低、慢呼吸、Z；整枝继续占位，不是假清空 | 入睡0.25–0.30s；稳定后可操作别枝 |
| 醒来 | 已睡满组激活后，睁眼/收Z/抬身，接“归巢”；不额外加完成数，不接受玩家拆组 | 0.12–0.18s，可与首只起飞准备衔接 |
| 归巢 | 等待群激活先醒/收Z→六只逐只起飞沿弧线到对应巢→近入口缩小淡出 | 单鸟0.50–0.60s，错峰约0.06s |
| 巢接收/目标更新 | 每鸟轻亮；末鸟后暖金光/巢弹/对勾→旧完成巢退出→新激活巢进入；再飞下一等待群 | 末段0.20–0.35s；不能飞向过期巢位置 |
| 临时枝启用 | 首次成功落鸟点亮“用过”标记，提示以后腾空收起；多次接鸟不累计寿命次数 | 约0.15s，与落稳衔接 |
| 临时枝退役 | 最后一鸟安全落位→空枝折叠/收拢→留下不可用痕迹；无鸟坠落、不重新排编号 | 0.20–0.35s；整链结束才解锁 |
| 开箱 | 条件确认→箱盖滑退淡出→原鸟短浮后落稳→检查外露蛋；不凭空多一排 | 0.35–0.55s |
| Undo | 短淡切/回落，整链状态回前一步；临时枝可复原，蛋回壳和原纹样；不再播放奖励 | 0.10–0.20s |
| 胜利 | 最后接收与连锁全部结束→HUD淡出→既定面板/奖杯鸟/三个星槽（亮星数按§3）/彩纸；末关仅Home/Replay | 彩纸约2.2s，主体稳定可点按钮 |
| 菜单退场 | 菜单Logo/按钮/装饰淡出至只剩背景；完成后串行进入棋盘段，背景连续 | 0.25s，不能与棋盘入场重影 |
| 按钮按压 | 按下scale1→0.92；松开经1.06回1。只在有效激活时发一次点击；禁用不播成功反馈 | 按下0.08s，松开0.18s |
| 按钮呼吸 | Play/Next稳定可点时scale1↔1.05；按压暂停呼吸、松开再恢复；禁用/后台停止 | 周期1.6s，减动画固定1 |
| 弹窗打开 | scale0.85→1.05→1，最前一段alpha0→1；仅主体稳定且对应结果有效才开放按钮 | 总0.25s，前0.10s淡入 |
| 弹窗关闭 | scale1→0.9且alpha→0；原模态输入锁保持到退出完成 | 0.15s |
| 遮罩/HUD退场 | 遮罩颜色/alpha按UI_SPEC；暂停/设置/死局不另淡HUD，胜利HUD独立淡出 | 遮罩淡入0.20s；胜利HUD淡出0.20s |
| 获星 | 保留三个槽，按§3实际所得逐颗点亮/弹出，未获槽不点亮；奖章非新增规则 | 每颗约0.35s，主体稳定后按钮可点，不等待全部彩纸 |

减少动画去大弧线、抖动、弹性和密粒子，保留状态顺序与短淡切；静音/灰度仍能识别鸟种、当前巢、睡眠、蛋与临时枝状态。现行系统减动画读取尚未接入，需列实现差异。验收留真实运行六帧时间采样及可播放录屏，不用静图拼接冒充已运行。

飞行使用脚底pivot：起止取前后稳定快照的真实槽位；控制点只改变曲线，不改逻辑token顺序。路径SHOULD向通道中央轻弯并避开巢/文字，左右镜像不反转数组；风格以现有fly姿势为准，不能仅平移站姿冒充扑翼。入巢容器是TargetNest；其入场是旧目标退出/新目标定位的阶段，不与RescueCover开箱混用。全局ReducedMotion允许上述大幅位移改成短淡切，但事件顺序/输入锁不变。

声音/触感：选择/落枝用轻短声，完成/归巢/开箱各给可区分短声，连锁限峰值避免六鸟六次同响叠爆；获胜声每次结算只播一次。已有音效优先复用；孵化/收枝专用声为待评审资源，不伪称已有。触感仅作为设备支持且系统允许时的轻反馈建议，不新增设置入口；静音/禁触感不能丢状态信息。后台暂停音效/装饰循环，回前台依DATA_SAVE稳定快照重建，旧viewGeneration回调全部失效。


## 2. 前端状态与输入契约

`Loading→Entering→Idle↔Selected→Resolving→Presenting→Idle/Won/NoMoves`；失败分支为`Resolving→SaveError→Presenting（确认成功）/Idle（确认未提交）/Menu（只读待核验或退出）`。模态、转场由UI管理，棋盘输入统一关闭；睡眠/箱/退役只是规则位置状态。

| 当前状态 | 可接收 | 必须拒绝/不缓存 | 退出时机 |
| --- | --- | --- | --- |
| Loading/Entering | 系统后台/退出 | 棋盘、撤销、重开、提示、Next | 布局和入场落稳 |
| Idle | 合法来源选择；有历史Undo；可用Hint；Restart；暂停 | 非法来源；无历史Undo、不可用/忙碌Hint | Undo/Restart按事务提交；Hint请求后仍Idle；选中则Selected |
| Selected | 同源/空白取消、目标尝试；有历史Undo；可用Hint；Restart；暂停 | 盖箱/睡眠/退役/蛋作为来源；无历史Undo、不可用Hint | 有效Undo/Hint/Restart/暂停先取消选中；Transfer进Resolving，非法目标回Idle |
| Resolving/Presenting | 系统后台；暂停仅记一个待打开请求 | Transfer、Undo、Restart、Hint、Next；连点不排队 | 逻辑已原子提交，且全事件播放+视图同步后 |
| SaveError | 重试核验/提交、返回菜单或退出（见DATA_SAVE失败分支） | 棋盘/Undo/Restart/Hint/Next；不自动重构另一个动作 | 确认提交成功才演出；确定未提交可回旧局；结果不确定的菜单保持只读 |
| Paused/Settings | 当前模态图标 | 棋盘/HUD穿透，后台自动补点 | 关闭回原稳定状态 |
| Won | Next（末关除外）、Replay、Home | 棋盘移动、重复奖励 | 明确导航 |
| NoMoves | 有历史Undo，或Restart | 看似可点实无历史的Undo | 恢复/重开稳定态 |

稳定态辅助动作的确定语义：

- Undo有效时先取消选中，再按DATA_SAVE提交整笔恢复，完成回Idle；没有历史时Idle/Selected/NoMoves均隐藏Undo（HUD保留固定空槽，不重排其他钮），不能出现彩色可点但无作用的按钮；无效请求不改选择或棋盘。
- Hint可用时先取消选中，从当前稳定快照/状态键启动一次非阻塞搜索，回Idle；不在等待期间锁棋盘。之后玩家可正常移动，旧答案因状态/事务号变化而丢弃。HintBusy或额度不可用时按钮禁用，不取消现选择、不扣次数，不堆并发搜索。具体预算/限次基线与候选变更见CODE_MAP。
- Restart有效时先取消选中，按DATA_SAVE原子提交初始局并清本局Undo/日志，成功后重新入场回Idle，失败保留原局/历史；不新增确认弹窗。
- Selected暂停先取消选中再开模态，关闭回Idle；Idle暂停关闭也回Idle。动画中的暂停仍只在事务/演出结束后打开。

暂停请求最多保留一个，事务完成后才开；系统杀进程以[存档](DATA_SAVE.md)原子边界恢复。每次关卡装载增加viewGeneration，旧协程/提示回调必须验证代次和状态键。不能让前关解锁新关输入。

## 3. 信息表达与辅助

- MUST保留既有图标按钮、极简设置、场景布局风格；已批准视觉细节以[UI_SPEC](../UI_SPEC.md)最新修订为准。新增蛋/临时枝信息不恢复已删文字按钮或章节条。
- MUST将蛋的种类纹样与对应鸟的轮廓/标记一致；壳与普通鸟姿态不同，不能误认为可直接搬的鸟。
- MUST在临时枝接收前就有“用后腾空收起”图示；Unused/Armed/Retired不只靠色相。首次教程用真实操作确认，不自动替玩家搬。
- SHOULD首次揭示前高亮可去位置，遇到非法目标只短反馈，不弹额外确认。
- MUST静音、灰度和减动画仍看懂目标/等待/容量/壳/退役。现系统减动画接口尚未实现，需明确验证状态。

**新版首版保留的帮助/评级政策（本节唯一权威）**：

| 项目 | MUST实现的首版政策 | 不属于首版的OPTIONAL变更 |
| --- | --- | --- |
| 星级 | 当前评级局Undo+Restart为0得3星、1–3得2星、≥4得1星；Hint不降星；保留最高星，不限制通关/解锁 | 通关固定奖章、效率奖章、不惩罚撤销的新评级未批准，不实现 |
| 评级局 | 未通关退出重进不清Undo/Restart计数；已通关Replay开新评级局；旧campaign成绩另归档 | 不因关号同号跨campaign继承新关完成 |
| 提示次数 | 每campaign/level总计3次，重开/重玩不补；新campaign从0次消耗开始，同campaign换hash保留消耗 | 分层提示或无限提示仅候选，不在本轮顺手扩展 |
| 求解响应 | 节点预算6000，UI等待1.5秒；返回已证明最优的合法首步且当前身份/状态有效才扣1；超时/未知/无解/失效不扣；旧搜索未结束不并发新搜索 | 不能用上界首步冒充当前政策已证明最优 |
| 展示 | 成功Hint高亮来源/目标，不自动替玩家移动；结算保留3个星槽但只亮实际获星数 | 不恢复已删步数行/设置滑条/章节UI |

这些参数保留现行产品政策，加入新规则后须复测其可用性；预算不够返回未知而不是改变规则/收费救援。现行代码事实另见[CODE_MAP](CODE_MAP.md)，未来政策变更须先更新本节并评审。

## 4. 资源与动画验收

新蛋和临时枝资源先盘点、独立派生、RGBA真透明、脚底/包围盒和灰度64px可辨，再接入；不可用近似重绘覆盖已验收切图。每项动画给真实运行6帧采样和时间记录，并保留可播放录屏。截图不能证明声音或输入锁，分别用真实交互和静音检查验证。具体质量/设备门槛见[验收](VALIDATION.md)。
