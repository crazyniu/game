# 小鸟归巢：可解性、公平性与验收

版本：规范设计1.0 · 2026-10-31 · **DESIGNED / PENDING_GRAYBOX**。规则可评审，不代表代码已支持。规范用语与优先级见[文档入口](../README.md)。

## 1. 验证与验收

### 1.1 先验证三组灰盒

见[灰盒合同](../LEVEL_DESIGN.md#7-先行灰盒与逐步推演)。先证明安全探蛋、临时枝重复借用/留一只、主动放弃临时枝的局面真实存在，再做1–5/11/21/22/25样板，最后扩40。灰盒是中间状态测试夹具，允许Armed非空，不等于正式关开局。

### 1.2 每关入库闸门

1. **固定性与结构**：Restart/Replay/重进同hash初态逐字段一致，无运行时随机补盘；每种六token含蛋/篮/箱；容量/目标/ID合法；临时枝开局空、容量4/5、无箱重叠；退役枝无token；蛋物种固定，数据不丢失。
2. **Core最优与回放**：新Solver区分蛋/鸟、临时生命周期、完成/箱/睡眠状态，键含rules/content身份；获得`Solvable && Optimal && Bound=Exact`并逐步回放到全归巢。预算耗尽=未知，拒绝或待调，不填假最优值。
3. **公平探索**：全知解只是下限证据；再给仅依据当时可见信息的安全探路、所有揭示分支的恢复证据；重点查蛋+临时枝是否迫使盲猜。
4. **机制有效**：记录孵化顺序、临时枝首次接收/多次接收/退役、篮进出、箱条件、自动连锁。禁篮/禁短枝/禁临时枝对照，只有证明无解/更长才写“必需/更优”。
5. **差异与节奏**：种类标准化、镜像、同条件位置重排做内容同构分析（不改变运行ID）；检查主决策签名，连续三关同模板必须重做。每五关有低负荷关，允许最优步数回落。
6. **实机与恢复**：真实无帮助胜利、输入锁、撤销整链、杀进程/恢复、不同屏幕/灰度/静音；JSON、求解证书、测试/录屏绑定同一hash。

蛋孵化可能零移动地合并同种块，旧“块数减一”下界不能直接沿用并宣称最优；先用0下界的正确搜索，或重新证明新下界。旧最优值和旧40关证书不为新布局背书。旧测试的minMoves/buriedBirds逐关不下降应在实施时评审更新，不能删守恒和最优证明测试。现行`List<int>`、`GetRun`、`Clone/GetStateKey`、`LevelValidator`、生成器、提示和存档均需适配，不能只加两个贴图就声称实现。

### 1.3 真人目标（待测）

至少5名新玩家先测灰盒，再测首五关和每章代表关；至少4/5在60秒内理解来源→目标、满组等待，且能在腾空前说出临时枝会收起。记录探蛋时的已知信息、首次误解、撤销点、主动退出点及“这关重复”的原话。若玩家一直回避临时枝，或永远留一只才可玩，重做布局或删机制，不增加强制使用任务掩盖问题。

期望时间仅调参：1–5约20–75秒，6–20约1–2.5分钟，21–40约2–4分钟，舒缓关回落；不用倒计时惩罚。首版不为调研新增SDK，人工记录即可。

## 2. 证明状态与证书

`NOT_RUN`未执行；`UNKNOWN`预算不足/取消/无法确定；`PROVEN_UNSOLVABLE`完整搜索证明无解；`SOLVED_UPPER_BOUND`有合法见证未证最优；`PROVEN_EXACT`合法解且最优。只有PROVEN_EXACT可写正式solverMinMoves并发布关卡；UNKNOWN不等于无解，记录预算和访问状态数。

每份证书MUST绑定rulesVersion、campaignId/catalogRevision、levelId、contentHash和求解器版本，记录动作序列/长度/预算/节点/终局键。每步按新Rules重放，Count与固定run相符，所有鸟/蛋/篮都计入，终局全部目标收集且无token。证书存独立报告，不把待验证0写入运行数据。

新增蛋可在一次计步移动的稳定化中零成本改变连续块数，旧下界没有证明就不能沿用；先h=0正确搜索，再证明可采纳新下界。优化不得合并临时枝状态、睡眠、箱、token形态不同的状态。内容去同构与运行精确状态键分开，运行不得因镜像重排改变自动归巢ID顺序。

## 5. 求解结果实例

| 结果 | 必须输出 | 禁止误报 |
| --- | --- | --- |
| 预算耗尽未找到解 | UNKNOWN，minMoves无效，记录预算/节点 | 不得写无解或可解 |
| 找到20步合法回放但预算耗尽 | SOLVED_UPPER_BOUND，upperBound=20，optimal=false | 不得填正式solverMinMoves=20或“证明最优” |
| 已证明最短18步且合法回放 | PROVEN_EXACT，minMoves=18，证书绑定hash | 不能拿另一布局hash证书复用 |
| 有限状态空间穷尽无解 | PROVEN_UNSOLVABLE，完整搜索证据 | 不能把超时、取消、无当前步等同此结论 |
