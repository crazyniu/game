## 2. 共同契约（每次必须附带）

```text
输入：本任务授权、RULES有效版本/R01..R06、固定关卡hash、前后稳定快照、带token ID的已提交事件、真实槽位、批准的资源/pivot、INTERACTION AN01..AN14和输入表、UI_SPEC必要UI-D行。缺输入先列缺口，不自由生成规则。
本版每关N=4/6/8、每种N；来源外露同种run到空/同端且有空间，实际搬量由RULES给定（SRC-SIMPLE的min边界），表现不得自行拆组/追加新孵鸟。完成群自动Home后该枝退场（SRC-BIRD2），不是普通腾空就折断。问号蛋（SRC-QUEST）数据固定、身份对玩家隐藏，不能用纹样/轮廓/预览泄露。
不存在双目标队列、未来群睡眠、精确条件箱、单座篮、混容量短枝或原Unused/Armed临时枝；禁止从旧素材/历史动画恢复它们。加枝/加高有同行功能依据但参数待证，当前40基础关不依赖、不擅画购买/容量按钮。
保持现项目角色与已定版鸟巢/枝/UI，不重画或以近似图替代。所有动画相关位置必须真实随时间变化，不用固定图冒充完成；飞行要振翅+轨迹，入巢要进入过程，结算要动态阶段/粒子。静态素材可组合为动作但不能只显示单张图。优先已批准的单一开源主补间库，不手写重复补间框架；选型/许可证状态读ANIMATION_LIBRARIES，未授权不安装，不能声称DOTween是MIT。布局用design px，不混PNG像素/pt/dp；脚底pivot对槽位，透明画布不是可见身宽。曲线只改表现，保持token原序和ID。
逻辑完整事务稳定并确认原子保存后才演出；动画不能决定奖励或规则。SaveError不播成功，后台/返回依稳定快照恢复；旧viewGeneration回调不能解锁新局。全链锁、不缓存连点；末只落稳再播已算后续事件。
按钮用圆或圆角矩形；能图标就只图标，不加重复可见文字，无障碍名称不是标签。设置简洁，只静音/恢复，不加slider/百分比或拆多个未批准项。声音/触感不改变玩法，系统不允许则安静呈现。
每个分镜列：任务模式→触发/前置→所需资产和不可变项→阶段/时间键/起止/层级/pivot→输入/后台/重入→终态→减动画/声音→禁止项→验收与未测边界。时长为项目建议非同行实测，不编新数字。
```

## 3. 动作块

### AP01 关卡开始：小鸟怎么出现

```text
触发固定关卡成功加载、Next或Restart；时间键AN01/AN02，UI-D07..10/34/36/38。来自菜单先Logo/按钮退场只留背景，再进入棋盘段；两段串行，加载另计，Restart不重播菜单。枝按固定位置出现，鸟逐只落真实初始槽、减速收翅站稳。问号蛋仍显示问号，不展示预定species；失效的双巢/睡眠/箱不入场。加载及入场锁棋盘和辅助，视图同步/全部落稳才Idle。减动画短淡入保留位置和身份；验收重复进入同hash初盘一致，无Logo重影或提前点选。
```

### AP02 选中、取消与非法操作

```text
触发Idle合法来源，AN03/AN04。只抬可搬的外露run，内层同种不抬；点同源/空白取消。非法目标原位反馈，不动鸟/不计操作；实际Transfer才以已提交Count飞行。无效辅助不改选择，有效Undo/Restart/Hint先取消。减动画保留描边；验收非连续同种、无空间、部分容纳、已完成退场位置、无历史Undo与提示忙碌。
```

### AP03 起飞、跨枝、落枝

```text
触发已提交Transfer，AN05、UI-D36/38。收选中态→用现角色并配验收多帧/骨骼clip转身和真实振翅；单fly图平移不通过→按Count逐只错峰弧线→脚底落目标槽→收翅回弹。起止来自快照，左右镜像不反转逻辑数组，最终ID相对序不受视觉先飞顺序影响。孵出的鸟不能追加入已锁本次Count。末只落稳才播已算Hatch/Home等后续事件。减动画取消大弧线/弹性短淡切；验收真实六帧/录屏、脚底/层级/数量、连续点击及后台重入。整群总长随N和错峰计算，不能固定六鸟。
```

### AP04 完成群归家／进入鸟巢

```text
触发RULES确认的Home事件，AN06，鸟巢资源仅是本项目“回家”主题表达。按当前N只已完成群依次沿弧线进入现有鸟巢，接近时收翅、脚底/入口对齐，使用已验收的鸟巢前后层资源实现遮挡，实际进入后再缩小淡出，末鸟轻亮/对勾；不允许飞离屏幕、单图平移或瞬间删鸟替代实际入巢。入口或前后层资源未验收时先列为资产缺口，不擅用归家出口替代，也不重画已定版鸟巢。用户“入笼/进笼”不代表新增锁笼/钥匙玩法。不等待顶部双巢资格，不睡眠，不靠动画生成目标顺序。
该群全部安全离开后衔接AP05完成枝退场。只接受逻辑已完成事件，动画不计算完成/奖励。减动画保留归群→枝退场顺序；验收不同N、完成与普通搬空区别、归家期间连点/后台，不飞向过期视图坐标。
```

### AP05 完成枝退场（替代已撤回的临时枝）

```text
SRC-BIRD2依据是排序完成一群飞走后失去该枝；仅消费Home之后的Retired事件，时间键AN07。让全部鸟安全离枝，再原位收拢/淡出枝并保留不可用痕迹和固定ID；不能因来源普通搬空、首次接过鸟或剩最后一只而触发。无Unused/Armed寿命标记、无坠鸟伤害。Undo恢复该完成事务前鸟/枝可用性；减动画用状态替换而非折断。验收普通搬空仍可用、完成才退场、Undo/Restart恢复；缺对应资产报待验收，不重画旧枝。
```

### AP06 问号蛋孵化

```text
SRC-QUEST只依据鸟前移走后?蛋孵化，具体合法边界取RULES。收到已提交Hatch后使用AN08：轻摇/裂壳→原位固定物种鸟→脚底站稳；孵化不增加token/随机换种，不靠点击或计时孵化。揭示前只画问号，禁止壳纹、剪影、声音或无障碍文本泄露种类。重开同题物种不变，Undo回原问号，不能重新抽。本版初态禁止相邻蛋，不演示自拟连蛋链；刚孵鸟不能追加本次run。减动画壳到鸟短切，保留先后。验收隐藏信息、守恒、固定重开、前端不提前曝光。
```

### AP07 结束、庆祝与按钮解锁

```text
触发最后Home/退场演出完且已Won，AN12..14，UI-D23..30。HUD退场→遮罩和既定面板→奖杯鸟庆祝/彩纸→主体稳定开放Replay/Home/合法Next。只展示RULES批准的通关与最佳操作数结果，不调用撤回的Undo惩罚星级，不因有三颗星素材就自动点满、发币或发皮肤。
末关没有越界Next；普通关Next指向固定下一关且遵地图已解锁状态。奖励/导航单次幂等，彩纸未结束可在主体稳定后操作。减动画短淡入静态结果；验收末关、重复Next、后台、声音一次，概念图不能代替运行证明。
```

### AP08 辅助、加载、返回与设置

```text
AN09..13，静态按钮尺寸取对应UI-D。Undo/Hint免费不限次，按钮不显示旧3次额度/收费广告；Hint未知或过期不谎称无解，不替玩家自动移动。一次只查一请求，状态变动丢弃旧答案。加枝/加高参数未冻结，只能给需求缺口，不画具体数量/价格/付费救场按钮。
按压反馈不缩命中区，禁用不触发；无历史Undo隐藏留槽，死局Restart取UI-D33。Loading/Presenting不缓存连点，返回/暂停防穿透；SaveError按DATA_SAVE核验同一候选而非自动重做动作。设置沿现有声音静音圆钮，音乐/游戏声/点击声可共用，禁止滑条/百分比。减动画按钮比例固定、模态短淡切；验收真实安全区/44pt或48dp换算、静音、连点锁和写档失败。
```

### AP09 世界地图及章节切换

```text
输入MAP_PROGRESSION全文及固定节点/进度；世界分段与解锁只按其合同，禁止另定阈值。主题为用户方向/概念，非已验收素材。固定节点内容和进度由数据给出，地图不能随机重排或修改关卡初态。
沿UI-U/UI-S统一画布/安全区/规则形图标按钮；锁/当前/通关状态用图标和轮廓，不仅色相。编号可见，返回/进入等能图标就不用重复文字，无障碍名称单独提供。节点坐标/新背景/动效资源未定标PENDING_LAYOUT，不改旧棋盘按钮尺寸、不拿概念图直接切资源。
分镜：地图稳定→选择合法已解锁节点→关闭地图输入→进入固定关卡AP01；返回时先读稳定进度再呈现地图，重复回调不能重复解锁。换世界沿同一布局骨架、短过渡，不新增复杂菜单。验收MAP_PROGRESSION指定章节边界、末关、已通关Replay与锁态，无越界或额外星门槛。
```

## 4. 通用验收模板

```text
按已授范围验收，列每项合同键及PASS/FAIL/NOT_RUN：token种类/数量/ID顺序；脚底/槽位/透明画布；AN键实测时序；普通搬空与完成失枝；问号不泄露；全链输入/后台代次；免费辅助且未知不谎报无解；地图章节边界；静音/灰度/减动画；真实触控安全区；SaveError/Undo与重复奖励。
真实运行记录六帧带时间戳、可播放录屏和交互证据；逐项核查全部动画位置确有随时间变化而非固定图，开源库实际选型/许可/单主库约束与文档一致。缺设备/引擎/已验收资产即NOT_RUN，别拿旧v2记录/静图/概念图或全知求解器结果替代本版本体验验收。
```
