# 小鸟归巢：给AI的动画任务模板

2026-10-31 · DESIGNED / PENDING_GRAYBOX。**本任务只写这些提示词，不执行模板、不生成素材、不改代码。** 本页提供未来任务模板，不给予未来执行者权限；实现或资产制作须另有明确授权。

## 1. 如何最快使用

先选择任务类型，再复制共同契约和所需动作块。必须将[INTERACTION](INTERACTION_ANIMATION.md)§1/2的完整表以及[UI_SPEC](../UI_SPEC.md)相关UI-D行作为本次输入，不能只给文件名让无文件访问的AI猜数值。时长唯一归INTERACTION，布局唯一归UI_SPEC；本页用稳定行名引用，不另定义竞争数值。规则事件顺序唯一归[RULES](RULES.md)，存档边界归[DATA_SAVE](DATA_SAVE.md)。

| 类型 | 可复制的角色前缀 | 必交结果 |
| --- | --- | --- |
| D：设计分镜 | 你是动画分镜AI。本任务只输出分镜和资源需求，不写代码或生成资产。 | 触发/前置→逐阶段姿态/轨迹/时间→输入时机→终态→减动画→验收；概念图标设计示意 |
| I：已授权实现 | 你是动画实现AI。先核对本次明确授权的代码/资源范围、工作地点和仓库规则；只实施授权部分。未授权或资产未验收的部分列缺口，Core等独立授权工作可继续。 | 绑定已提交事件与现资产的实现、取消/重入处理、实际运行证据及未验证边界；禁止由本模板推定授权 |
| A：验收 | 你是只读验收AI，除本任务另有明确许可外不改文件。按提供的合同核对真实运行结果。 | 时间采样、实际/预期、六帧与录屏、输入/后台/灰度/静音结果；无运行条件明确NOT_RUN |

## 2. 所有动作共同契约（连同动作块一起复制）

```text
产品是固定关卡、端部同类整理、六鸟自动归巢。输入包含：本任务授权范围、规则版本/关卡hash、前后稳定快照、带token ID的已提交事件列表、真实槽位、现资产manifest/pivot、INTERACTION时间和输入表、UI_SPEC相关尺寸行。缺任一必需信息先列缺口，不补随机内容或伪造运行证据。
保持现鸟、巢、栖木、按钮、面板、字体与背景；不得重画或替换已验收UI。新蛋/临时枝仅用单独验收的派生资产；没有素材时给缺口，不用近似图冒充完成。
使用design px；不要把完整透明画布当可见身宽，也不把design px当pt/dp。起落使用脚底pivot、真实位置和鸟种正确fly姿势。曲线/错峰顺序是表现；逻辑token原序、容量、目标、箱条件、蛋种类均不变。
Core先完整计算稳定终态并原子确认存档，再播事件；动画仅消费事件，不靠帧回调推进规则/奖励。SaveError不播成功。全链输入锁、不缓存连点；暂停最多暂存一次。后台/退出/重进验证viewGeneration，旧协程不能解锁新局或发重复奖励。需要恢复时显示已提交稳定快照。
每个动作输出：任务类型；输入资产/不可变项；触发/前置；按阶段列时间键、对象/姿态/层级、起止/曲线/pivot；输入/后台/重入；终态；声音/触感；减动画替代；负面约束；可判定验收。时长取附带INTERACTION行，布局取附带UI-D行，禁止另发明参数。
```

## 3. 动作块（选一个或串行组合）

### AP01 关卡开始：鸟怎么出现

```text
触发：初次进入、Next或Restart成功装载同一固定初态。引用时间键“菜单退场/入场”，尺寸UI-D07..10、UI-D34..38。
来自菜单时先让Logo/按钮/装饰退场，背景保留；完成后再HUD与棋盘进入，两个段串行、加载另计。Restart不重复菜单段。目标巢先定位清楚，两列枝按固定位置依次进场，鸟逐只从上方到各自真实槽位、展翅减速、脚底落枝、收翅站稳。
蛋、箱与睡眠显示按加载状态，不在入场擅孵蛋/开箱/赠满群。Entering锁棋盘与辅助钮，所有对象落稳并同步后Idle，不排队执行连点。减动画用短淡入保留对象身份与槽位，禁止Logo与盘面重影。验收固定重开数组相同、首帧到Idle完整录屏、首个可点时间、无提前操作。
```

### AP02 选中、取消、非法操作

```text
触发：Idle选择合法端部run；时间键“选中/非法操作”。只把当前可搬run抬起和描边，蛋、箱、睡眠/退役不得误选，中间隔开的同种不抬。再点同源/空白取消回落；非法目标只短反馈，取消并回Idle，不移动token、不记操作。
来源高亮与真正Move Count区分：合法容量不足只飞Count，其余回落。辅助动作按输入表先取消选择；无历史Undo/禁用Hint不改变选择。减动画保留描边。验收同种非连续/蛋阻隔/余量不足/空白取消，截图不能代替状态差异核对。
```

### AP03 起飞、跨枝、落枝

```text
触发：合法Transfer已稳定提交；时间键“移动起飞/弧线与落枝”，尺寸UI-D36/38。输入事件中已锁定run/Count、来源前态、目标后态槽位及token IDs。
收选中态→转身换fly→可见扑翼→按Count逐只错峰离枝→向通道中央的弧线→目标脚底接枝→收翅小回弹。飞行首只可为最外鸟，但最终逻辑数组保留提取切片原序，不能由视觉先飞顺序改ID。末只落稳后只播放已计算的后续孵化/归巢事件。
减动画取消大弧线/弹性，短淡切到正确槽位；输入锁仍到整链同步。音效短且限叠。禁止站姿整排平移、全枝瞬移、飞Count以外鸟、刚孵出的同色追加本次飞行。验收脚底/遮挡层级/弧线6帧、真实时序、容量截断例、连续连点、后台重建。
```

### AP04 满组睡眠与醒来

```text
触发：六只已孵化同种完成但非当前两个目标。时间键“满组等待/醒来”。群体逐只闭眼压低、轻呼吸和Z，仍占满原枝且冻结，不能表现为空枝或可搬。
目标刷新激活睡眠组时先睁眼抬身收Z，再接AP05；完成数不重复增加。稳定睡眠后可操作别枝；一旦开始连锁继续全链锁。减动画静态闭眼/Z→醒来图像替换，颜色之外也能识别。验收未来组先睡、激活后自动飞、Undo同时恢复睡眠/目标/计数。
```

### AP05 进入鸟巢、巢入场和目标更新

```text
触发：已提交的Home/AutoHome事件，不能新增手动Dispatch按钮。时间键“归巢/巢接收/目标更新”，UI-D37。用户“入笼/进笼”在这里指归巢接收容器TargetNest；不是救援盖箱RescueCover，不新增锁门/鸟笼美术。
若来自睡眠先AP04醒来；六鸟逐只沿弧线飞向本批次绑定的激活巢入口，临近入口缩小淡出，每鸟接收轻亮，末鸟暖金光/巢弹/对勾。完成巢退场、新目标从顶部进入并定位；先更新目标视图再飞下一等待群，不能把鸟飞到过期坐标。接收容器有入场/退出阶段，绝不是直接删枝上六鸟。
整批与连收全部播完才解锁；快进/后台不重发奖励。减动画保留逐群接收、对勾和新目标定位，短淡切替大弧线。验收一次收第二目标、两群连续自动归、每群6只/正确种与巢、目标刷新顺序及Undo。
```

### AP06 救援箱/盖笼揭示（与AP05严格分开）

```text
触发：已确认Reveal事件；时间键“开箱”。RescueCover遮来源枝，不是目标巢。不擅自画鸟笼/锁或补钥匙玩法，使用批准的盖箱资源。
先明显提示本次完成条件满足，再盖滑退/淡出，露出原来那组鸟；短浮落稳，按事件继续最外蛋孵化。不得凭空生成新鸟排、把所有内层蛋同时孵化。多箱先按固定shelves数组的批次事件呈现，再各枝孵化/完成；表现不能改规则顺序。减动画直接揭示并保留条件图标。验收睡眠也可开箱、RevealAfter与RevealSpecies不同、揭前后token数守恒。
```

### AP07 固定物种蛋孵化

```text
触发：无遮挡且成为最外露token的蛋收到Hatch事件；时间键“孵化”。输入必须给原token ID、固定species、壳纹样、孵后鸟资产；蛋仍占一格，不直接搬进篮。
前鸟离开后轻摇→短裂壳→原位同种鸟→脚底站稳，未外露的后蛋保持蛋。孵化不加token、不随机物种、不加当前飞行Count；没有点击孵化按钮。壳纹样在小尺寸/灰度可读；缺独立验收资产先报缺口。减动画壳→鸟短淡切。验收连蛋每次仅一颗、箱遮时不孵、Undo恢复同一壳/ID/种、同种不追飞。
```

### AP08 临时枝三态与收起

```text
触发与状态：初始空4/5座Unused，未使用空枝不消失；首次有效接鸟后Armed；以后首次完全腾空在稳定化末尾Retired。引用时间键“临时枝启用/临时枝退役”，容量与ID由关卡输入给出，不增第六座。
接鸟前已有“用后腾空收起”图示；首次鸟安全落稳后显示已用标记。Armed可反复接同种，留最后一只不收，但不能因此接异种。最后鸟安全落目标后，空枝折叠/收拢，原位置留不可用痕迹、不重新编号。无断枝伤鸟/坠落/倒计时。Undo短恢复整事务，Unused/Armed/Retired均准确。
减动画用静态三态图标/轮廓，不能仅靠颜色。验收非法点选不Armed、2进1出仍Armed、二次接收、最后全出才Retired、重开Unused和Undo恢复。
```

### AP09 结束、奖励与按钮解锁

```text
触发：最后一群AP05接收及所有已提交连锁演出结束，逻辑已Won。时间键“胜利/遮罩/HUD退场/弹窗打开/获星”，尺寸UI-D23..30。
最后鸟到巢→HUD淡出→遮罩与既定面板进入→奖杯鸟庆祝→只点亮本局实际所得星→彩纸。保留3槽，禁止每次强发3星；星级只读取INTERACTION§3合同/结算结果，不在动画计算规则。主体稳定且结果有效即可按钮交互，不等待彩纸全部结束。末关仅Replay左/Home右，无越界Next；重复点不重复发奖或跨两关。
减动画取消弹性/彩纸，保持稳定结果、星数和图标位置。验收1/2/3星、末关/普通关、快速Next、后台/退出恢复、声音只一次；无真实运行录屏不能写通过。
```

### AP10 按钮、禁用、加载、返回与Undo

```text
引用时间键“按钮按压/按钮呼吸/弹窗打开/弹窗关闭/Undo”，静态尺寸取UI-D对应页，命中验收取UI-S01。
按压缩放只改变图像反馈，不缩命中区；禁用不触发、无历史Undo隐藏留槽，死局Restart按UI-D33居中。Loading/Entering与事务中拒绝辅助及导航连点，不缓存动作。返回由当前模态关闭或明确Home导航决定；Busy暂停只暂存一次，禁止穿透棋盘。SaveError必须按DATA_SAVE保留候选核验重试，不能永久转圈或播成功。
Undo播放的是已提交恢复快照，整笔蛋/箱/目标/临时枝一起复原，不重新结算。减动画固定按钮比例、简短模态淡切；声音/触感遵共同合同和系统允许，不新增设置开关。验收禁用连点/无历史/提示并发/SaveError/真实44pt或48dp换算/安全区；截图不能证明这些交互。
```

## 4. 统一验收提示词（配合任一动作）

```text
按本次授权做验收，不因存在提示词自行实施。逐条列合同键、实际证据、PASS/FAIL/NOT_RUN。
至少核对：输入/输出token种类数量与顺序；脚底与槽位/画布透明留白；计时单位、错峰和整群总长；当前巢与等待巢；全链锁和取消/后台/viewGeneration；灰度/静音/减动画；真实安全区及逻辑触控尺寸；失败写档与Undo；重复奖励/越界Next。
真实运行留六个关键时刻并有时间戳、可播放录屏和实际交互日志。设计分镜/生成图标“示意”，不能写实机通过。缺资产、无法跑引擎、未做设备试验明确剩余项，不用旧v2记录替代新版。
```
