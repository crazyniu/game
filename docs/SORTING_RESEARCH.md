# 分类整理益智：参考玩法文字手册与本项目取舍

核查日期2026-10-31。类型称 **Sort Puzzle / Sorting Puzzle（分类整理益智）**；瓶间倒液体是Water Sort，球是Ball Sort，鸟是Bird Sort。这里是把同类归组，不是按大小排队，也不自动等于三消。下文自包含具体玩法，链接仅供溯源，AI无需打开商店才能理解。

证据标签：**录像观察**只证明已看到片段；**官方介绍**是开发者公开声明，不等于本轮安装实测或逐关验证。所有“自拟示例”仅说明局部策略，不是原作关卡/实录路径或完整可解证书。A/B表示颜色或种类，端部是当前可取那端。未知批量/空容器/障碍算法、道具额度或广告频率不凭品类经验补全。我方采纳结论与本项目六鸟、min(run,free)、蛋纹样及临时枝规则，绝不混为竞品事实。

## 1. Cutie Sort：整理成组与目标队列联动

**证据：录像观察及用户提供材料的核验记录；不是六关完整操作转录。**

- 目标：混排猫按同色凑组，再配合顶部当前房屋目标收集；形成满组与已收集是两个状态。
- 操作：先选来源架可操作端，再选接收位置；已观察连续同色成组搬移、空架或同色外端接收。左右列从朝中央的外露端取，不能抽中间猫；容量限制存在，本文未从片段断言所有拆组算法。
- 完成与等待：每架六只。满六符合当前目标则逐只收集，未来目标满组趴睡占位；目标刷新匹配后自动收集。睡眠不是失败，全部目标收集才结算。精确卡住检测/全部道具成本未核实。
- 变体与功能：顶部目标替换、睡眠、纸箱揭示、暂存篮；官方道具名称含撤销、交换、扩容。观察到普通×1箱随满组事件揭示新排、颜色箱随对应种完成揭示，但全部精确边界未实测。第2关是五色各六、十条非空架，不能写开局有空架；第6关棕组睡眠与箱揭示的事件先后不足以推断所有箱公式。
- 自拟示例：当前A/B，先凑C可能占住整架等待；先处理A可能更新目标并腾出空间。仅解释完成/收集区别，不对应实录次序。
- 我方迁移：目标队列、等待占位、连续群体与因果反馈；不只换猫成鸟，不照搬原关/广告栏位。所有尚未核实边界在我方RULES独立定义。
- 未验证：每关完整解法、所有箱触发边界、道具额度/商业化成本、动画毫秒。

来源：[官方商店](https://play.google.com/store/apps/details?id=sort.casual.color.cat.puzzle.match&hl=en)、[视频1](https://www.youtube.com/watch?v=fZHsuXpTwEE)、[视频2](https://www.youtube.com/watch?v=onptn300img)。

## 2. Water Sort Puzzle／IEC Global：有限容器归色

**证据：官方Google Play介绍。**

- 目标：让每个装水杯的内容成为单色。
- 操作：点来源杯，再点接收杯倒水；上层颜色匹配、接收杯有空间才能倒，不符合则不能倒入。该正文未完整交代空杯接收和一次倒多少，不把本项目部分移动算法套给原作。
- 终局/卡住：全部杯子单色完成，规划失误可卡住并重开；单指、离线和平滑倒水反馈。后续更多杯/复杂布局是官方宣称，不等于证明每关策略不同。
- 功能/限制：商店标广告/IAP；撤销额度、特殊障碍及广告触发未核实。
- 自拟示例：目标顶色A且余一格，接来源顶部A能露出其下B。说明合并/揭层，不是原关卡。
- 我方迁移：容量可读、空位调度；不将增种/背景换色当新玩法，不引入广告通关门槛。

来源：[官方商店](https://play.google.com/store/apps/details?hl=en_US&id=com.gma.water.sort.puzzle)。

## 3. Ball Sort Puzzle - Color Game／Guru：离散单位与试错

**证据：官方Google Play介绍，不把玩家广告投诉视为所有版本规则。**

- 目标：同色球集中到各瓶。
- 操作：点来源瓶顶球，再点目标瓶；目标顶球同色且有空间，瓶容量四球；压住的内部球不能抽出。介绍按单球讲解，不证明实际所有模式永远只搬一球。
- 终局/卡住：归类完成即通关；无倒计时/重开惩罚，可重开。
- 功能/限制：Undo、Add加瓶、离线，广告/IAP。Undo是否无限、Add成本、全部模式批量/障碍未核实。
- 自拟示例：四格目标已有A3，可接一颗A；满四即使同色也不能放。
- 我方迁移：清楚栖位、免费回退试错；不以付费或广告额外空间修补无解关卡。

来源：[官方商店](https://play.google.com/store/apps/details?hl=en-US&id=ball.sort.puzzle.color.sorting.bubble.games)。

## 4. 3D Colorful Sort Magic Water／Gaming Laboratory：信息/空间机关

**证据：官方Google Play介绍；具体机关未实测。**

- 目标：各容器水归为单色。
- 操作：点来源杯再接收杯，顶层同色且有空间；不能把普通杯条件未经核实套到锁柜中的容器。
- 终局/卡住：全单色完成；Undo、Shuffle、加管可解困，主体宣称无时间压力。
- 变体：遮布、冰块、钥匙锁柜、卷帘、问号水层；地图/壁纸奖励，提杯/倒水/揭布对应声；另有竞速、连胜、体力等活动，广告/IAP。
- 自拟示例：先处理可见内容才能读更多隐藏信息；只是信息压力示意，不声称所有遮布都用此动作揭开。
- 我方迁移：条件开空间、可预判揭示、事件音效；拒绝随机洗牌、体力、转盘/竞速混搭。容器换鲸鱼/玫瑰造型不自动算规则创新。
- 未验证：消冰次数、钥匙来源、卷帘触发、提示成本和各模式失败条件。

来源：[官方商店](https://play.google.com/store/apps/details?hl=en&id=com.magic.relaxing.water.sort.colorgame.puzzle)。

## 5. Bird Sort／Leafy Games：连续鸟群与树枝容量

**证据：开发者官方商店描述。**

- 目标：将混排鸟按类整理到树枝。
- 操作：选来源枝外侧连续同色鸟群，再选目标枝；空枝或外端同色且未超容量可以接收，内部被挡鸟不能抽出。
- 终局/卡住：同类整理是完成方向；撤销/重开、不限时。完整结算判定、满枝是否冻结未被资料确认。
- 功能/限制：外观解锁、撤销和重开；精确移动批量、容量不足如何截断、外观成本未验证。不能因鸟主题认定也有Cutie目标队列/睡眠/箱。
- 自拟示例：外侧A2挡B，先将A2送可接A端才露B；余量不足如何处理不自定为原作事实。
- 我方迁移：群飞、端部标记、剩余容量可读；“换鸟+点枝”本身不作为创新卖点。

来源：[官方商店](https://play.google.com/store/apps/details?id=com.leaf.birdsort)。

## 6. Bird Sort Quest／mobirix：移前鸟以露蛋

**证据：开发者官方商店描述。**

- 目标：整理鸟群并推进前方鸟遮住的内容。
- 操作：选端部鸟再选接收枝，允许移到空枝；移开前方鸟可使问号蛋孵化。非空接收完整条件未确认，不能直接套另一游戏。
- 终局/卡住：按鸟种整理；精确终局条件未核实。介绍称无时间/行动点限制，含撤销/加额外枝。
- 功能/限制：问号蛋揭示、外观、日常活动。物种算法、相邻蛋一起孵否、撤销重抽否和额外枝成本未知。
- 自拟示例：把蛋前鸟移到空枝让蛋露出，揭示前不能假定其中正好是A。
- 我方迁移：露端孵化的自然主题；改写成固定物种、壳纹可预告，减少盲猜。这是我方决定，不称原作已有纹样预告。

来源：[官方商店](https://play.google.com/store/apps/details?id=com.mobirix.ldbis)。

## 7. Nut Sort Mania／Gameware：长短杆与中转价值

**证据：开发者官网/官方介绍；可解是官方声明，不是我方独立证明。**

- 目标：不同色螺母按色归杆。
- 操作：选来源杆顶部颜色，再选空杆或顶部同色杆转移；有短/中/长杆。批量与容量不足截断未确认。
- 终局/卡住：同色归类完成；可提示/撤销。Smart Assist声称检查可解性，开发者称关卡无需道具可解。
- 功能/限制：异长度杆、可解性帮助、日挑战。具体长度/帮助算法/预算/收费未知。
- 自拟示例：长杆承担更多暂存，先占满它可能使后来所需色无接收空间；不指定原作杆长数字。
- 我方迁移：普通短枝已实现，深化周转；无道具可解要求要我方独立验证。搜索超时是未知，不以加枝补关卡缺陷，不采纳强制限时。

来源：[开发者页面](https://www.gamewareeurope.com/Public/games?id=nutsort)、[官方商店](https://play.google.com/store/apps/details?id=com.gameware.nutsort)。

## 8. Goods Sort／EXO：邻近三同清除与后排

**证据：开发者官方商店描述；属于邻近整理消除，不与水/鸟排序完全同核。**

- 目标：同类商品凑同货架，以三同清除推进。
- 操作：先点商品再点货架空位；前排三同消失后露后排。不能把空位理解成覆盖现物，后排是否可直接取/锁位条件未确认。
- 终局/卡住：反复清前排处理后层；各模式必须全空或限时与否未核实。已有Undo/Hint。
- 功能/限制：前后层、离线、日奖励；精确失败、自动连锁范围和道具费用未知。
- 自拟示例：A2+一空位接第三A，清除后露下一层；非录像关卡。
- 我方迁移：完成前层释放后层的因果；不加入三同消除，不增加另一套胜利目标。

来源：[官方商店](https://play.google.com/store/apps/details?id=com.exostudio.goodssort)。

## 10. 采纳、改写与不采纳

| 候选 | 首版决定 | 原因与本项目独立定义 |
| --- | --- | --- |
| 空间周转、不同长度容器 | 保留现有短枝/篮 | 已实现，不称新增创新；确保每关真正改变解题路径，而非只摆道具 |
| 鸟蛋/后层揭示 | **采纳并改写为可预判孵化** | 蛋占原鸟一格，固定物种并用壳纹样提示；露端孵化、阻断run，锁定本次移动数量，不随机加鸟；问号盲猜不进首版 |
| 条件救援/开新区域 | 深化现有箱 | 计数阈值、指定种、睡眠完成开路、双条件不同节奏；规则写全且避免自锁，不能套未验证竞品钥匙触发 |
| 临时空间消耗 | **采纳为独立原创临时栖枝规则** | 开局空cap4/5，第一次接鸟Armed，之后第一次腾空Retired；可反复接收，留末只只接同种；这不是已经在上述竞品实测的事实 |
| 目标顺序与归巢连锁 | 保留并加强内容 | 鸟群自然回家、当前与未来目标取舍；自动连收流畅反馈，无需每群手动确认 |
| 免费撤销/重开与帮助 | 保留；分层提示待评审 | 鼓励探索与恢复；求解超预算不能谎报无解；不用广告和额外空枝补本来不可解关 |
| 外观/地图/壁纸/日挑战 | 后续候选 | 有研究依据，但不直接解决首版40关重复；不在本轮扩大美术、联网或奖励经济 |
| 高对比、形状标记、减动画 | 纳入可达性目标 | 让状态和鸟种不只靠色相；具体系统减动画读取需实现，不能说当前已支持 |
| 强制计时、体力、竞速、随机洗牌、抽奖 | 不采纳 | 与可推理、随时可停、离线低压力定位不符；会混淆可玩性与资源消耗 |
| 主动放飞+共享风闸 | 后续灰盒实验，非首版 | 能产生时机决策，但需大改自动归巢、动作集、提示/死局/存档与UI；先验证更自然的蛋和临时枝，不让40关变一种门态题 |

临时枝的触发边界、纹样蛋的公平规则、箱与目标组合、每五关舒缓及结构同构检查，都是我们的设计决定。来源说明功能可能存在，不证明其体验优秀，也不证明我们的新关已可解。

## 11. 统一成一款游戏的原则

保留同一移动规则、同一六鸟目标、同一套可撤销因果。每关只改变“先释放谁、留哪段空间、哪个完成事件开路、何时允许临时枝退场”，而不是突然要求倒水、拧螺丝或三消。首版只重点新增蛋与临时枝，其余多样性用已有空间/目标/救援组合产生。

关卡六类轮换见[40关目录](LEVEL_DESIGN.md)，完整状态与验收见[PRD](PRD.md)。所有机制要有实际合法解、错误回退、可见信息判断和真人观察；“同类产品也有”“关卡很多”“颜色更多”都不构成可玩性验收。
