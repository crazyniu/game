- 新campaign：A开放，仅01可开始；同世界按关号先后解锁。通关n才解锁n+1。已解锁关可重复进入，固定同hash内容不变。
- A全部01–08完成→B开放且09可开始；B全通→C；C全通→D。此门槛是USER世界顺序要求的本项目明确配置，不归因给竞品。没有星数/金币/广告/等待时间门槛。

## 3. 表现与存档

通关事务同时提交completedLevelIds及由它推导的解锁；完成群/关卡庆祝/世界开放提示只是该终态的表现，不用动画回调发第二次奖励。第一次开世界演出可记录seenWorldIntro，仅控制是否重播，不改变锁态。后台恢复到已提交进度，不因录屏中途退出重复开世界。

worldId是固定关卡身份的一部分；换主题美术不改逻辑hash，换章节归属/关卡内容需catalog修订和兼容检查。具体字段/版本仅DATA_SAVE定义。跨campaign不按同关号继承新关已通关；旧v2/T16设计成绩归档可读。
